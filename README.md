## 🌟 作品介绍

**VoiCal (Voice Calendar)** 是一款专注于**极致输入效率**的现代 Web 日历应用。  
通过集成强大的语音识别引擎和针对中文语境优化的自然语言处理（NLP）模块，用户只需自然地说出一句话（例如：*“明天下午三点在二楼会议室开会”*），系统即可自动提取时间、事件与关键信息，并瞬间同步到日历看板中。

### 核心特性
- **⚡ 毫秒级语音指令解析**：采用纯净 16000Hz 降采样 WebSocket 音频流，确保识别引擎不再受到底噪或采样率不匹配的干扰，极大地提升了识别精度。
- **🧠 智能中文时间提取**：内置基于 `chrono-node` 的定制化中文 NLP 引擎，支持相对时间（明天、下周三）、模糊时间（早上、晚上）甚至“智能纠错”（如自动将“早上23点”纠正为正确的“晚上11点”）。
- **🔁 周期性日程支持**：支持“每天”、“每周五”等周期性指令的语音识别与循环渲染。
- **🎨 极客与优雅并存的设计 (Impeccable Design)**：支持深色/浅色主题无缝切换，精调的自定义滚动条、微交互动效（如语音识别时的波形动画），提供极佳的沉浸式体验。
- **🔒 隐私与离线优先**：日程数据完全使用 IndexedDB (Dexie.js) 本地存储，无需云端数据库，绝对保护隐私。

## 🏗️ 技术架构

本项目在开发过程中经历了深度的架构打磨，最终确立了兼顾性能与可维护性的最佳实践：

1. **前端核心栈**
   - **原生 JS (Vanilla JS) + Vite**：极致的首屏加载速度，摒弃了厚重的框架历史包袱。
   - **FullCalendar**：提供强大、可靠的月/周/日视图渲染底座。
   - **Dexie.js**：对原生 IndexedDB 进行优雅封装，提供高性能的本地数据流转。
2. **音频引擎流转架构**
   - 为了彻底解决“多模块争抢麦克风导致死锁”的痛点，我们设计了**单向音频数据流**：`SpeechManager` 独占获取 `MediaStream`，然后将纯净流共享给 `Visualizer` 模块进行波形绘制，彻底消除硬件并发冲突。
   - **前置强制降采样 (Software Downsampling)**：无视操作系统的音频采样率霸权（如锁死的 48000Hz），前端通过自定义算法强制按精确比例将 PCM 音频降采样至 16000Hz 后，再通过 WebSocket 喂给后端 ASR，实现了识别准确率的指数级飞跃。
3. **后端 ASR 架构**
   - **Node.js + `ws`** + **Sherpa-ONNX**：通过原生 Node.js 绑定调用底层的 Zipformer/Paraformer 模型，避免了原本将百兆级模型文件放到前端 WASM 加载导致的崩溃与卡顿。

## 🚀 快速开始

### 1. 环境准备
- Node.js (v18+)
- 推荐使用 npm 或 pnpm

### 2. 安装依赖
```bash
npm install
```

### 3. 一键启动 (前后端同时启动)
```bash
npm run dev
```
> 此时，Vite 前端服务器将运行在 `http://localhost:3000`，后端的 WebSocket 语音识别服务将运行在 `ws://localhost:3002`。

## 🤝 开发过程与代码规范

- 采用模块化的项目结构，将 UI 控制 (`ui.js`)、语音捕获 (`speech.js`)、NLP 解析 (`nlp.js`) 和 数据存储 (`storage.js`) 完全解耦。
- 注重异常边界处理：包括网络断开提示、麦克风权限拒绝处理、空内容自动过滤等。
- CSS 采用现代 CSS Variables 与 Flex/Grid 布局，适配多种分辨率，并实现了优美的高分辨率屏幕波形重绘(`window.devicePixelRatio`)。
